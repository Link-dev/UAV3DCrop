# UAV3DCrop

Official project page for **UAV3DCrop: Benchmarking 3D Reconstruction in
Repeated Multi-Angle UAV Crop Surveys**.

UAV3DCrop is a large-scale benchmark for evaluating 3D reconstruction across
crop types, growth stages, and repeated multi-angle UAV acquisitions.

## Project page

https://link-dev.github.io/UAV3DCrop/

## Dataset access

- [UAV3DCrop RGB imagery](https://huggingface.co/datasets/Link-Dev/UAV3DCrop)
- [UAV3DCrop depth data](https://huggingface.co/datasets/Link-Dev/UAV3DCrop_depth)
